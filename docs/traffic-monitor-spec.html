01

Giới thiệu & phạm vi

Tài liệu này chuẩn hoá yêu cầu gốc (docs/README.md) thành đặc tả kỹ thuật có cấu trúc: mỗi yêu cầu có mã định danh, mỗi module có hợp đồng (interface) rõ ràng, mỗi lỗi có cách xử lý, mỗi tính năng có tiêu chí nghiệm thu.

Sản phẩm
Ứng dụng desktop PySide6

Chạy cục bộ trên Windows, xử lý video bằng YOLO + ByteTrack, hiển thị realtime.

Đầu vào
Video file · Webcam · RTSP

Bắt buộc: video file. Webcam/RTSP: kiến trúc sẵn sàng qua interface VideoSource.

Đầu ra
MP4 · JSON · CSV · Log

Video đã annotate, báo cáo phiên, danh sách sự kiện, file log ứng dụng.

Phạm vi

Trong phạm vi

  • Phát hiện 4 loại phương tiện: car, motorcycle, bus, truck.
  • Tracking bằng ID, đếm qua 1 LineZone ngang, đo tốc độ qua 1 vùng perspective 4 điểm.
  • Cảnh báo SPEED_VIOLATION realtime, dashboard, event log.
  • Xuất video, JSON, CSV; cấu hình qua GUI và file YAML.
  • Unit test cho 6 thành phần lõi (model YOLO được mock).

Ngoài phạm vi (v1.0)

  • Nhận dạng biển số (ANPR), phát hiện vượt đèn đỏ, lấn làn.
  • Nhiều counting line / nhiều camera đồng thời.
  • Lưu trữ cơ sở dữ liệu, giao diện web, phân quyền người dùng.
  • Huấn luyện lại model (chỉ hỗ trợ thay file .pt).

Pipeline xử lý frame

FrameProcessor.process_frame(frame) thực thi đúng thứ tự dưới đây cho mỗi frame. Kiểu dữ liệu ghi dưới mỗi bước là đầu ra của bước đó.

1detectnp.ndarray → sv.Detections
2filterconf ≥ thr ∧ class ∈ vehicles
3trackByteTrack + Smoother → tracker_id
4countLineZone.trigger → in/out ids
5speedanchor → mét → km/h
6alertspeed > limit → Alert
7annotate→ annotated_frame
8dashboard→ statistics dict
Chuẩn hoá bước “dashboard”FrameProcessor không vẽ GUI. Bước 8 chỉ tổng hợp số liệu thành statistics; Worker phát statistics_updated để GUI tự cập nhật.
app/video/frame_processor.py — hợp đồng
@dataclass(frozen=True)
class FrameResult:
    annotated_frame: np.ndarray            # BGR, cùng kích thước frame vào
    detections: sv.Detections              # đã có tracker_id
    statistics: dict[str, Any]             # TrafficStatistics.to_dict()
    new_events: list[TrafficEvent]         # event phát sinh trong frame này
    frame_index: int

class FrameProcessor:
    def process_frame(self, frame: np.ndarray) -> FrameResult:
        detections = c.detector.filter_detections(c.detector.detect(frame))
        detections = c.tracker.smooth(c.tracker.update(detections))
        crossings = c.counter.process(detections)
        speeds = c.speed_estimator.update(detections, time_s, c.zone_manager.in_speed_zone(detections))
        events = self._crossing_events(crossings, speeds, time_s)        # VEHICLE_IN / VEHICLE_OUT
        events += self._speed_alerts(detections, speeds, time_s)         # SPEED_VIOLATION
        violation_mask, labels = self._labels(detections, speeds)
        annotated = c.renderer.render(frame, detections, labels, violation_mask, ...)
        return FrameResult(annotated, detections, self.statistics(len(detections)), events, self._frame_index)

Vùng perspective (ZoneManager) chỉ giới hạn việc đo tốc độ. Xe nằm ngoài vùng này vẫn được track và đếm.

Chuyển frame OpenCV → QImage (trong worker)
def to_qimage(frame_bgr: np.ndarray) -> QImage:
    rgb = cv2.cvtColor(frame_bgr, cv2.COLOR_BGR2RGB)
    height, width, channels = rgb.shape
    return QImage(rgb.data, width, height, channels * width, QImage.Format.Format_RGB888).copy()
app/gui/processing_worker.py — khung
class ProcessingWorker(QObject):
    frame_ready = Signal(QImage)
    statistics_updated = Signal(dict)
    event_created = Signal(dict)
    processing_started = Signal(dict)
    processing_finished = Signal(dict)
    error_occurred = Signal(str, str)

    @Slot()
    def run(self) -> None:
        try:
            self._monitor.open()                               # load model + mở source
            self.processing_started.emit(self._monitor.session_info())
            for result in self._monitor.iter_results():
                if self._stop_requested.is_set():
                    break
                self._resume_event.wait()                      # PAUSE
                self._emit_result(result)
        except TrafficMonitorError as exc:
            logger.error("Processing failed: %s", exc)
            self.error_occurred.emit(exc.title, str(exc))
        finally:
            self.processing_finished.emit(self._monitor.close())

Đo tốc độ bằng Perspective Transform

Camera nhìn xiên nên khoảng cách pixel không tỉ lệ với khoảng cách thật. Ta ánh xạ vùng mặt đường hình thang (4 điểm trên ảnh) thành hình chữ nhật có kích thước thật road_width_m × road_length_m.

Thuật toán

  1. Lấy anchor BOTTOM_CENTER của mỗi detection: detections.get_anchors_coordinates(sv.Position.BOTTOM_CENTER).
  2. Biến đổi sang mét: ViewTransformer.transform_points.
  3. Lưu (frame_index, x_m, y_m) vào deque(maxlen=int(fps)) theo tracker_id (cửa sổ ~1 giây).
  4. Không tính ở frame đầu; chỉ tính khi elapsed ≥ min_track_seconds (mặc định 0.5 s).
  5. speed_kmh = |v| × 3.6, trong đó v là vận tốc hồi quy tuyến tính (least squares) của x_m(t), y_m(t) trên cả cửa sổ.
  6. Detection có cạnh dưới bị xe phía trước che (geometry.occluded_bottom_mask) không được lấy mẫu và lịch sử của nó được làm lại; giá trị > 250 km/h bị loại.
Vì sao không dùng hiệu hai đầu (điểm đầu – điểm cuối)Khi kiểm thử trên vehicles.mp4, công thức hai đầu cho ra 204–221 km/h. Nguyên nhân là xe bị che một phần hoặc box đổi kích thước khiến anchor nhảy vài mét giữa hai frame. Sau khi dùng hồi quy và loại mẫu bị che, xe tải đo được 77–81 km/h, xe con 84–150 km/h, tốc độ lớn nhất 159 km/h.
Time baseVới video file, thời gian tính theo frame_index / fps của video — tốc độ đúng kể cả khi máy xử lý chậm hơn realtime. Với camera/RTSP, dùng time.monotonic() tại thời điểm đọc frame.
app/vision/transformer.py
class ViewTransformer:
    def __init__(self, source: np.ndarray, target: np.ndarray) -> None:
        self._matrix = cv2.getPerspectiveTransform(source.astype(np.float32), target.astype(np.float32))

    def transform_points(self, points: np.ndarray) -> np.ndarray:
        if points.size == 0:
            return points.reshape(-1, 2)
        reshaped = points.reshape(-1, 1, 2).astype(np.float32)
        return cv2.perspectiveTransform(reshaped, self._matrix).reshape(-1, 2)

# target = [[0, 0], [W - 1, 0], [W - 1, L - 1], [0, L - 1]]  với W = road_width_m, L = road_length_m
app/core/speed_estimator.py — calculate_speed
def calculate_speed(self, tracker_id: int) -> float | None:
    history = self._history.get(tracker_id)
    if not history or len(history) < 2:
        return None                                   # không tính ở frame đầu tiên
    (frame_start, x0, y0), (frame_end, x1, y1) = history[0], history[-1]
    elapsed_s = (frame_end - frame_start) / self._fps
    if elapsed_s < self._min_track_seconds:
        return None
    speed_kmh = math.hypot(x1 - x0, y1 - y0) / elapsed_s * 3.6
    self._speeds[tracker_id] = speed_kmh
    return speed_kmh

Validate perspective_source

  • Đúng 4 điểm, mỗi điểm 2 số nguyên; thứ tự A (trên-trái) → B (trên-phải) → C (dưới-phải) → D (dưới-trái).
  • Tứ giác lồi, diện tích > 0, không có 3 điểm thẳng hàng.
  • Sai ⇒ PerspectiveError; hướng dẫn chạy python scripts/calibrate_perspective.py --video data/samples/x.mp4 để click chọn 4 điểm và ghi vào config.yaml.
